========================================
  POLKA DOT - Telegram Bot для заказов
  Инструкция по настройке
========================================

ШАГ 1: Создайте бота в Telegram
-------------------------------
1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте /newbot
4. Введите имя бота: Polka Dot Orders
5. Введите username: polkadot_orders_bot
6. Скопируйте ТОКЕН (вида: 1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ)

ШАГ 2: Узнайте ваш Chat ID
-------------------------------
1. Найдите вашего бота в Telegram
2. Отправьте ему любое сообщение (например /start)
3. Откройте в браузере:
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
4. Найдите строку: "chat":{"id": ЧИСЛО_ВАШЕГО_ID
5. Скопируйте это число

ШАГ 3: Настройте сервер
-------------------------------
1. Откройте файл bot/server.js
2. Замените YOUR_BOT_TOKEN_HERE на ваш токен
3. Замените YOUR_CHAT_ID_HERE на ваш chat_id

ШАГ 4: Запустите сервер
-------------------------------
1. Откройте терминал в папке bot/
2. Выполните: npm install (если нужно)
3. Выполните: node server.js
4. Сервер запустится на http://localhost:3001

ШАГ 5: Настройте деплой (для работы 24/7)
------------------------------------------
Вариант A: Railway.app (бесплатно)
  1. Зарегистрируйтесь на railway.app
  2. Подключите GitHub репозиторий
  3. Автоматический деплой

Вариант B: Render.com (бесплатно)
  1. Зарегистрируйтесь на render.com
  2. Создайте Free Web Service
  3. Укажите папку bot/ и команду: node server.js

Вариант C: Vercel (бесплатно)
  1. Установите: npm i -g vercel
  2. Выполните: vercel deploy

ШАГ 6: Обновите URL на сайте
-------------------------------
В файле script.js замените:
  const BOT_SERVER = 'https://polkadot-api.vercel.app';
на ваш реальный URL сервера.
